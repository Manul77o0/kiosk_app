# Echo Show 5 Kiosk

This repository contains an Android kiosk app for Echo Show 5, experimental
Linux display configuration, and an optional sensor receiver.

- `app/`: Android application
- `linux/`: Experimental Linux setup (see [linux/README.md](linux/README.md))
- `server/`: Sensor receiver (see [server/README.md](server/README.md))

Build the Android app with:

```sh
./gradlew assembleDebug
```
